# research
Research for fire predictions.

Team research for NASA Space Apps 2026, challenge
[Harmonization of MODIS and VIIRS Hot Spots](https://www.spaceappschallenge.org/2026/challenges/modis-and-viirs-hot-spots/).

## Contents

- [`showcase/`](showcase/): research website with data previews, feature triage and team decisions (see its README to run it).
- [`docs/project-idea.md`](docs/project-idea.md): project proposal, harmonization method, features, timeline, open questions.
- [`docs/feature-catalog.md`](docs/feature-catalog.md): candidate features, how to promote each, video and slide plan.
- [`docs/interface-inspiration.md`](docs/interface-inspiration.md): survey of existing fire and climate apps, interface patterns per screen, wireframe, UI libraries.
- [`docs/literature-study.md`](docs/literature-study.md): reading list of 13 papers and what each gives the project.
- [`docs/data-sources-extended.md`](docs/data-sources-extended.md): extra data sources for validation, context and future sensors.
- [`docs/hackathon-brief.md`](docs/hackathon-brief.md): challenge, data access, submission rules, judging.
- [`docs/data-findings-romania.md`](docs/data-findings-romania.md): first numbers from FIRMS data for Romania.
- [`Wildfire Data Sources.md`](Wildfire%20Data%20Sources.md): catalog of fire-related datasets.
- [`docs/source/`](docs/source/): raw text of the challenge page, submission guide and judging criteria.
- [`CLAUDE.md`](CLAUDE.md): context file that AI coding assistants load automatically.

The `docs/` files and `CLAUDE.md` were drafted with an AI assistant (Claude) for the team to review.
