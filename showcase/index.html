One consistent fire record for any area, 2000 to today

The challenge: harmonize NASA's MODIS and VIIRS hotspots into a burning-activity calendar in a web app, so the sensor no longer matters. This page gathers everything in the repo so far and lets the team decide what to build.

    What's inside the files

    Record types per sensor. Type 2 = industry and other static heat, 3 = offshore. MODIS records rarely carry type 2, so we mask those spots ourselves.
