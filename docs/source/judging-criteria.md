# Judging criteria (excerpt)

Source: https://www.spaceappschallenge.org/resources/judging-awards-guide/ (fetched 2026-11-14)

Each criterion is scored 1 to 5. The text below quotes the "score of 5" descriptions.

- **Impact:** "This project demonstrates exceptional impact, addressing a significant problem with proposed
  solutions. Its reach is extensive, inspiring, benefits a large audience, or could change the world."
- **Creativity:** "This project showcases remarkable creativity, introducing a groundbreaking approach that has
  never been attempted before. It challenges conventional methods, presenting an original and inventive proposed
  solution that stands out in its field."
- **Validity:** "This proposed solution is scientifically sound and technically feasible, demonstrating strong
  alignment with established principles. It is fully developed and ready for real-world implementation,
  effectively achieving its intended purpose. The project is highly usable and user-friendly."
- **Relevance:** "This project thoroughly engages with the challenge, delivering a proposed solution that is
  deeply connected to the intended goals. NASA data is integral to the project's success, providing meaningful
  insights that drive the innovation forward."
- **Presentation:** judged mostly from the project submission page; a strong demo can raise this score.
